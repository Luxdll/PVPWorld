# PVP World

Прототип MOBA

Две команды — выжившие и заражённые — сражаются на улице заброшенного города. Игрок управляет героем выживших и помогает союзным бойцам уничтожить базу противника.

## Запуск проекта

Для запуска откройте проект в Unity 6000.0.29f1, затем сцену Assets/Scenes/MOBA.unity и нажмите Play.

## Управление

- **WASD** — движение героя.
- **Мышь** — направление прицеливания.
- **Левая кнопка мыши** — стрельба; можно удерживать.
- **«Играть снова»** — начать новый матч после завершения текущего.

## Цель и завершение матча

Уничтожьте базу заражённых и защитите базу выживших.

- Уничтожение базы заражённых приносит победу выжившим.
- Уничтожение базы выживших приносит победу заражённым.
- После завершения матча бой останавливается, появляется результат с указанием победившей команды.
- Кнопка «Играть снова» полностью перезапускает матч.

Гибель управляемого героя не завершает матч: через **10 секунд** он возрождается на стартовой позиции с полным здоровьем.

## Реализованные механики

- Две команды, базы и автоматически стреляющие башни.
- Периодические волны бойцов и автоматический выбор вражеской цели.
- Дальняя атака выживших и ближняя атака заражённых.
- Пули проходят через союзников.
- Полосы здоровья над героем, бойцами и башнями.
- Верхняя панель с названием игры, таймером матча и здоровьем обеих баз.
- Нижняя панель здоровья героя и отсчёт до возрождения.
- Камера, следующая за героем.
- Арена с дорогой, разметкой, тротуарами, зданиями и бетонными заграждениями.
